# 02: SNI parser

**Status:** done · **Crate:** erbridge-core · **Blocked by:** none

**What to build:** `sni` module that reads the first TLS record from a stream
(cap 16 KiB, 5 s timeout) and extracts the SNI, returning it with the buffered
bytes so they can be replayed.

## Acceptance

- Parses real ClientHellos generated by rustls (with and without SNI, IP-literal
  names excluded).
- Case-insensitive match helper.
- Rejects: non-TLS bytes, truncated records, oversized records, handshake that
  is not a ClientHello, malformed extensions. Never panics (fuzz-style test over
  truncations of a valid hello).
- Slow sender hits the timeout.
